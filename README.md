# โต๊ะซ้อมศึก

โต๊ะซ้อมกติกาการ์ดบนเว็บ สำหรับเดินเด็ค 50 ใบ, LIFE 5 ใบ, การจ่าย GEM, โซ่เวท และช่วงต่อสู้

การ์ดในโปรเจกต์นี้เป็นใบซ้อมที่เขียนขึ้นใหม่ ไม่ใช่การ์ดทางการ และ GEM ยังไม่มีสี

รายละเอียดว่าทำอะไรไปแล้ว และอะไรยังติด อยู่ใน [บันทึกงาน.md](บันทึกงาน.md)

## เล่น

```bash
npm install
npm run dev
```

จากนั้นเปิดหน้าแรก เลือกเด็ค แล้วลงสนามกับคู่ซ้อม หรือสลับเครื่องสองคน

เด็คที่มีให้ซ้อม: ซิ่งปากซอย, ศาลปากซอย, แถวเพื่อนซอย
